# REPO CONTEXT
This file contains important context about this repo for [Tonkotsu](https://www.tonkotsu.ai) and helps it work faster and generate better code.

## Setup
```bash
# Install dependencies (Node 24.12 or newer)
npm install
```

## Build
```bash
# Build the project
npm run build
```

## Lint
```bash
# Run linting
npm run lint
```

## Tests
```bash
# Unit and API route tests (Node's built-in runner)
npm test
```

## Dev Server
```bash
# Start the development server
npm run dev
```

## Production Server
```bash
# Start the production server
npm run start
```

## Additional Notes
- This project uses Next.js 16 (Pages Router) and React 19
- Firebase is used for authentication and database
- See CLAUDE.md for architecture notes and conventions
